# snake

Roblox but you are a snake.

**Block Snake** — 플레이어가 뱀이 되어 블록으로 만들어진 3D 아레나를 돌아다니는 3인칭 게임입니다.
카메라는 뱀 머리 뒤를 따라다니고, 몸통은 머리가 실제로 지나간 경로를 그대로 따라옵니다.

의존성이 전혀 없습니다. 빌드 도구도, 엔진도, `npm install`도 필요 없습니다.
렌더러는 순수 WebGL로 직접 작성했고, 효과음은 WebAudio로 합성합니다.

## 실행 방법

`index.html`을 브라우저에서 열면 끝입니다 (파일을 더블클릭해도 동작합니다).

로컬 서버로 띄우고 싶다면:

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

### 단일 파일로 묶기

공유하거나 아무 데나 올리기 좋은 자체 포함 HTML 한 개로 만들 수 있습니다:

```bash
node tools/bundle.js              # dist/blocksnake.html (약 81 KB, 단독 실행)
node tools/bundle.js --fragment   # <head>를 직접 제공하는 호스트용 조각
```

스크립트 9개를 그대로 인라인하므로 `index.html`과 동작이 동일합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `A` / `D`, `←` / `→` | 좌우 조향 |
| `Shift` (또는 `Space`, `W`) | 부스트 — 스태미나를 소모하고 회전 반경이 커짐 |
| 마우스 드래그 | 조향 (좌우 위치가 조향량) |
| 마우스 휠 | 카메라 거리 조절 |
| `P` / `Esc` | 일시정지 |
| `M` | 음소거 |
| `J` | 화면 조이스틱 켜기 / 끄기 |
| `Enter` / `R` | 시작 · 재시작 |
| **화면 조이스틱** | 왼쪽 아래 스틱을 밀어 조향, 오른쪽 아래 `BOOST` 버튼 |
| **게임패드** | 왼쪽 스틱 조향, `A`/`B`/`RB`/`RT` 부스트, `Start` 일시정지 |

터치 기기에서는 화면 조이스틱이 자동으로 나타납니다. 데스크톱에서는 `J` 키나 HUD의 `stick`
칩으로 켤 수 있습니다. 게임패드는 연결해서 아무 입력만 주면 바로 인식됩니다.

## 게임 규칙

- **먹이**를 먹으면 점수와 몸 길이가 늘어납니다. 빨간 먹이는 10점 / +3칸, 황금 먹이는 30점 / +7칸입니다.
- **콤보**: 2.6초 안에 연속으로 먹으면 배수가 최대 ×5까지 올라갑니다.
- **죽는 조건**: 벽, 블록 기둥, 자기 몸통, 그리고 라이벌 뱀의 몸통.
- **라이벌 뱀 3마리**가 같은 아레나에서 먹이를 두고 경쟁합니다. 라이벌이 내 몸통에 부딪히면
  터지면서 먹이를 흘리고 60점을 줍니다. 즉, 상대를 몸으로 가로막아 잡을 수 있습니다.
- 라이벌은 각자 반응 속도와 조심성이 달라서, 덜 조심한 개체는 꼬리로 유인해 잡기 쉽습니다.
- 점수가 올라갈수록 뱀이 조금씩 빨라집니다.
- 최고 점수는 `localStorage`에 저장됩니다.

```

src/math3d.js       4x4 행렬 / 벡터 / 보간 등 최소한의 3D 수학
src/glcore.js       WebGL 컨텍스트, 셰이더 프로그램, 메시, 인스턴스 배치
src/snake.js        뱀 시뮬레이션 (머리 이동, 경로 기록, 몸통 샘플링)
src/world.js        아레나, 먹이, 장애물, 라이벌 AI, 충돌, 점수
src/render.js       셰이더와 씬 구성 (하늘 → 바닥 → 그림자 → 솔리드 → 발광)
src/camera.js       3인칭 추격 카메라
src/input.js        키보드 / 마우스 / 터치 / 게임패드 입력
src/joystick.js     화면 조이스틱 (드래그, 노브 추적, 스프링백)
src/audio.js        WebAudio 효과음 합성
src/main.js         프레임 루프, HUD, 미니맵, 게임 상태
tools/bundle.js     단일 HTML 파일로 묶는 스크립트
tests/logic.test.js 시뮬레이션 로직 테스트
```

### 몸통이 경로를 따라오는 방식

머리는 매 프레임 위치와 누적 이동거리를 트레일에 기록합니다. `i`번째 몸통 칸은
`머리의 누적거리 - (i+1) × 간격` 지점을 트레일에서 보간해 가져옵니다. 덕분에 몸통이
코너를 자르지 않고 머리가 지나간 곡선을 그대로 따라갑니다. 트레일은 몸 길이만큼만
유지하고 뒤쪽은 버리므로, 오래 플레이해도 메모리가 늘지 않습니다.

### 조이스틱 · 게임패드 조향

키보드와 마우스 드래그는 **회전 속도**를 직접 줍니다 (좌/우로 얼마나 빨리 돌지).
스틱은 대신 **방향**을 줍니다: 스틱을 민 방향을 카메라 기준으로 월드 방향으로 바꾸고
(`M3.stickToHeading`), 뱀이 그 방향으로 짧은 쪽으로 돌아갑니다. 덕분에 뱀이 카메라를 향해
달려오는 상황에서도 "화면 왼쪽으로 밀면 화면 왼쪽으로" 돕니다. 화면 조이스틱과 게임패드
왼쪽 스틱이 이 로직을 공유합니다.

### 렌더링

큐브 하나를 인스턴싱해서 뱀, 벽, 기둥, 먹이, 파티클을 전부 그립니다 (한 프레임에 draw call
네 번). 그림자는 바닥에 깔린 반투명 쿼드, 먹이 표시는 가산 블렌딩된 빛기둥입니다.
WebGL2가 있으면 그대로 쓰고, 없으면 WebGL1 + `ANGLE_instanced_arrays`로 동작합니다.

### 라이벌 AI

후보 조향값 5개를 각각 약 1.2초 뒤까지 시뮬레이션해서, 가장 오래 살아남고 목표에 가까워지는
값을 고릅니다. 벽·기둥·자기 몸·플레이어 몸을 피하고, 다른 라이벌은 현재 위치가 아니라
**예상 위치**를 기준으로 피합니다 (그래야 정면 충돌 전에 서로 비켜갑니다).
초당 몇 번만 다시 계산하므로 부하가 낮습니다.

## 테스트

```bash
node tests/logic.test.js
```

WebGL이나 DOM 없이 순수 시뮬레이션(수학, 뱀, 월드)을 검증합니다 — 몸통이 경로를 따라오는지,
충돌·점수·콤보·스태미나가 맞는지, 트레일 메모리가 제한되는지, 라이벌이 몇 분 동안
사고 없이 돌아다니는지, 스틱 방향이 카메라 기준으로 올바르게 변환되는지 등 37개 테스트입니다.
